Alles an einem Ort

DropForge bündelt häufige Datei-Aufgaben in einer nativen App — ohne Upload, Konto oder Cloud-Zwang.

So sieht es aus.

Installation

  1. DMG laden und öffnen.
  2. DropForge in den Programme-Ordner ziehen.
  3. Beim ersten Start Control-Klick auf die App und „Öffnen“ wählen.
  4. Falls macOS blockiert: Systemeinstellungen → Datenschutz & Sicherheit → „Dennoch öffnen“.

Der aktuelle Build ist ad-hoc signiert und nicht von Apple notarisiert. Deshalb zeigt macOS diesen zusätzlichen Sicherheitsschritt.

Privatsphäre

DropForge ist local-first: Datei-Workflows laufen auf deinem Mac. Die App enthält keine eigene Telemetrie; Netzwerkzugriff erfolgt nur für optionale Updateprüfungen. Diese Website bindet keine eigenen Analytics- oder Werbetracker ein und wird über GitHub Pages ausgeliefert.
